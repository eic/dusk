# Overview

`dusk` is an OpenCASCADE-based replacement for DAWN that renders STEP detector
geometry into SVG views.

## Tools

- `dusk`: render a STEP file to SVG with configurable camera and draw mode.
- `duskcut`: cut a STEP geometry with a half-space plane (same interface
  convention as `dawncut`).

## Why Docsify here

This repository now ships a Docsify site for lightweight project docs and
publishes CI-generated visual outputs (including fixture gallery pages) via
GitHub Pages.
